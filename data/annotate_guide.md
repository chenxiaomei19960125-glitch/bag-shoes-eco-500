# 素材画面标注规范（鞋靴/箱包，前30秒）

项目根目录：`/Users/chenxiaomei/CodeBuddy/20261008234900`

## 输入
对每个拼图编号 NNN：
1. `read_file` 读 `assets/review/NNN.jpg`：若干行，每行上方抬头 `[j] key | ECO | skip | play | ctr | cost | dur | cuts30 | video/image`，下面一行是该素材前30秒的关键帧（时间点 0.3/1.5/3/5/8/12/16/20/25/29.5 秒，帧左下角黄字为秒数；短视频帧更少；image 为静态图只有1张）。
2. `read_file` 读 `data/review_text/NNN.txt`：每条素材逐帧 OCR 到的字幕文字（可能为空或有错字）。
3. 看不清时可再读单帧 `assets/frames/<key>/00.jpg` ~ `09.jpg`（宽360）。

## 输出
把该张全部素材标注写成 JSON 数组，保存为 `data/annotations/NNN.json`（UTF-8，2空格缩进）。条目数与抬头一致（通常5条，最后几张可能少于5条）。先读 `data/annotations/001.json` 作为格式样例。

## 字段
- `key`：如 `"r12"`，必须与图片抬头一致
- `framework`（九选一）：
  - 剧情型：两人及以上对话/情节（劝说、搭讪、问询、惊喜、反转、家庭/职场情景），或单人演绎生活情节
  - 人设口播型：单人真人对镜讲解（老板/店主/博主/导购），主体是"人在说"
  - 产品展示型：以产品为主体（手持、摆拍、开箱、上脚/上身局部、功能/收纳演示），有人但人不是叙事主体
  - 街拍穿搭型：户外/街头/商场上脚上身穿搭、走秀、变装、路人穿搭种草
  - 测评实验型：破坏、极限、对比、防水耐磨测试，强调结果
  - 工厂溯源型：原料、工艺、车间、仓库、老板带看工厂
  - 情感送礼型：送礼/收礼主题
  - 直播切片型：直播间画面/直播 UI
  - 图文型：静态图、电商卡片/海报轮播
- `type`（优先从下列选，都不合适写"其他·xxx"，≤8字）：
  - 剧情型：路人劝说剧 / 搭讪问询剧 / 惊喜反转剧 / 家庭情感剧 / 身份反差剧 / 生活情景剧
  - 人设口播型：老板店主口播 / 博主种草口播 / 选购科普口播 / 反常识避坑口播 / 叫卖促销口播
  - 产品展示型：手持转面展示 / 上脚上身局部 / 开箱展示 / 功能细节演示 / 收纳容量演示 / 摆拍展台
  - 街拍穿搭型：街拍上脚混剪 / 穿搭变装 / 户外场景实拍 / 路人穿搭种草
  - 测评实验型：破坏极限测试 / 对比测评 / 防水耐磨演示
  - 工厂溯源型：原料工艺奇观 / 工厂车间实拍 / 老板带看工厂
  - 情感送礼型：送礼开箱 / 收礼反应
  - 直播切片型：直播间讲解
  - 图文型：白底单图 / 电商卡片轮播 / 海报轮播
- `person`：真人露脸主导 / 真人露脸辅助 / 仅身体局部 / 无人物
- `face3`：0.3/1.5/3 秒三帧中是否出现清晰真人正脸（true/false）
- `product_first`：所推广产品（鞋/包/箱/袜/皮带等）首次成为画面主体的时间点秒数（取 0.3/1.5/3/5/8/12/16/20/25/29.5 之一）；10 帧都不是主体则 `null`；静态图为 0
- `product_frames`：产品为画面主体的帧数（整数，≤该素材帧数）
- `hook`（按 0–3 秒画面+字幕选一）：冲突对话 / 悬念反常识 / 身份人设 / 视觉奇观 / 测试结果悬念 / 好奇种草 / 痛点人群点名 / 价格利益 / 情感送礼 / 卖点直述 / 无钩子
- `hook_text`：开场标题/字幕原文（≤24字，仅修正确定的 OCR 错字），没有则 `""`
- `price`：30 秒内画面或字幕是否出现价格/折扣/券/到手价/买一送一（true/false）
- `story`：≤45字，按时间概括前30秒，如 "0–3秒…；5–12秒…；16–30秒…"
- `confidence`：高 / 中 / 低

## 原则
只依据画面与字幕判断，绝不编造口播内容或画面里没有的信息；看不清就把 `confidence` 标为"低"，并在 `story` 里写明哪一段看不清。JSON 必须合法可解析。
